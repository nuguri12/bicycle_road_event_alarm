# Location Extraction

## 1. 위치 추출 목표

위치 추출은 이벤트가 실제로 자전거 주행에 영향을 줄 수 있는 지역과 장소를 찾는 단계입니다.

출력 필드:

- location_name
- region
- cyclist_impact_reason에 사용할 위치 근거

## 2. 지역 범위

MVP 대상 지역:

- 서울특별시
- 경기도

서울 주요 후보:

- 한강
- 여의도
- 잠실
- 반포
- 뚝섬
- 망원
- 잠원
- 광나루
- 청계천
- 중랑천
- 탄천
- 안양천

경기도 주요 후보:

- 고양
- 하남
- 구리
- 남양주
- 성남
- 과천
- 안양
- 광명
- 부천
- 김포

## 3. 추출 우선순위

1. raw_location_text에 있는 장소
2. raw_body에 있는 장소
3. raw_title에 있는 장소
4. source_name 또는 source_url로 추론 가능한 장소

source_name 기반 추론은 낮은 신뢰도로 취급합니다.

## 4. 장소명 표준화

규칙:

- 행정구역 접미사는 유지합니다.
- 공원, 교량, 하천, 자전거도로 명칭은 가능하면 유지합니다.
- 여러 장소가 있으면 대표 장소 1개와 본문 요약용 보조 장소를 분리합니다.

예:

- `여의도한강공원`은 `여의도 한강공원`으로 표준화합니다.
- `잠실대교 남단`은 구체 위치로 유지합니다.

## 5. 모호한 위치 처리

모호한 예:

- `행사장 일대`
- `시내 주요 도로`
- `한강변`
- `서울 일원`

처리:

- 구체 장소가 없으면 `needs_review`로 둡니다.
- 자전거 영향 판단 사유에 "구체 구간 확인 필요"를 포함합니다.
- Telegram 메시지 발행 후보에서는 기본 제외합니다.

## 6. 사용자 입력 필요 항목

- `[사용자 입력 필요]` 우선 감시할 서울 자전거 주요 구간 목록
- `[사용자 입력 필요]` 우선 감시할 경기도 자전거 주요 구간 목록
- `[사용자 입력 필요]` `서울 일원` 같은 넓은 위치 표현을 발행 후보로 둘지 여부
