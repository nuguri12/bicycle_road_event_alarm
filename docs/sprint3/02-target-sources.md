# Target Sources

## 1. 출처 선정 기준

MVP 출처는 다음 기준을 만족해야 합니다.

- 공식 또는 공공성이 높은 출처입니다.
- 서울 또는 경기도 자전거 이동에 영향을 줄 수 있습니다.
- 날짜, 장소, 원문 URL을 얻을 수 있습니다.
- 과도한 인증이나 복잡한 세션이 필요하지 않습니다.
- robots 정책과 서비스 이용 조건을 존중할 수 있습니다.

## 2. 1순위 출처 후보

### 2.1 서울경찰청 교통정보센터

후보 URL:

- `https://www.spatic.go.kr/`

예상 수집 정보:

- 교통 통제
- 집회 또는 행사로 인한 도로 영향
- 서울 주요 도로 통행 제한

선정 이유:

- 자전거 주행에 직접적인 영향을 줄 수 있는 교통 통제 정보입니다.
- MVP 가치인 "피해야 할 구간"과 가장 직접적으로 연결됩니다.

구현 전 확인 필요:

- 목록 페이지와 상세 페이지 URL 구조
- 정적 HTML 수집 가능 여부
- 게시글 날짜와 통제 구간 추출 가능 여부

### 2.2 서울시 공식 공지

후보 URL:

- `https://www.seoul.go.kr/`

예상 수집 정보:

- 서울시 행사 공지
- 대규모 축제
- 도로 통제 안내
- 하천 또는 공원 행사 안내

선정 이유:

- 서울 전역 이벤트의 공식 출처입니다.
- 행사성 이벤트를 넓게 포착할 수 있습니다.

구현 전 확인 필요:

- 검색 결과 또는 공지 목록의 안정적인 URL
- 키워드 검색 가능 여부
- 상세 페이지에서 날짜와 장소 추출 가능 여부

## 3. 2순위 출처 후보

### 3.1 서울시 한강사업본부 또는 한강공원 관련 공지

후보 URL:

- `https://hangang.seoul.go.kr/`

예상 수집 정보:

- 한강공원 행사
- 자전거도로 주변 축제
- 공원 이용 제한

선정 이유:

- 한강 자전거도로 이용자에게 영향도가 높습니다.

### 3.2 경기도 공식 공지

후보 URL:

- `https://www.gg.go.kr/`

예상 수집 정보:

- 경기도 행사
- 도로 통제 공지
- 하천 또는 공원 행사

선정 이유:

- 서울 외곽 및 경기도 라이딩 그룹에 필요합니다.

## 4. 초기 MVP 추천 순서

1. 서울경찰청 교통정보센터
2. 서울시 공식 공지
3. 한강공원 관련 공지
4. 경기도 공식 공지

이 순서는 통제 정보의 직접성, 구현 난이도, 자전거 이용자 영향도를 기준으로 합니다.

## 5. 사용자 입력 필요 항목

- `[사용자 입력 필요]` 1차 구현 출처 1개 선택
- `[사용자 입력 필요]` 서울과 경기도 중 우선 지역 선택
- `[사용자 입력 필요]` 공식 출처 외 커뮤니티 또는 행사 플랫폼을 제외할지 여부
- `[사용자 입력 필요]` robots 정책 검토와 출처별 수집 허용 여부 확인 담당자
