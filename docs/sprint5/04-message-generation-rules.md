# Message Generation Rules

## 1. 메시지 목표

Telegram 메시지는 출발 전 빠르게 읽는 알림입니다. 상세 안내문이 아니라 피해야 할 구간을 알려주는 짧은 경고입니다.

## 2. 메시지 구성

기본 구성:

1. 제목
2. 주의 이벤트 목록
3. 원문 링크

예:

```text
이번 주말 자전거 주의 구간

1. [주의 높음] 여의도 한강공원 - 토요일 오전
   마라톤 행사로 혼잡 또는 통제 가능성이 있습니다.
   원문: https://example.com
```

## 3. 영향도 표시

표시명:

- high: `주의 높음`
- medium: `주의`
- low: `혼잡 가능`

unknown과 none은 메시지에 포함하지 않습니다.

## 4. 이벤트 수 제한

MVP 기본값:

- 최대 5개 이벤트

이유:

- 15초 안에 읽기 어렵지 않게 유지합니다.
- 작은 그룹 알림의 실용성을 유지합니다.

## 5. 문장 규칙

- 한국어로 작성합니다.
- 한 이벤트는 1~2문장 이내로 작성합니다.
- 장소와 날짜를 먼저 씁니다.
- 불확실한 정보는 "가능성"으로 표현합니다.
- "반드시", "확정" 같은 단정 표현은 원문에 명시된 경우에만 사용합니다.
- 개인별 우회 경로를 제안하지 않습니다.

## 6. 금지 문구

금지:

- "최적 경로는..."
- "반드시 안전합니다"
- "통제 확정" 단정 표현
- 입력에 없는 시간대
- 입력에 없는 장소

## 7. 사용자 입력 필요 항목

- `[사용자 입력 필요]` 최대 이벤트 수 5개 승인 여부
- `[사용자 입력 필요]` 영향도 표시명 승인 여부
- `[사용자 입력 필요]` 메시지 제목 문구 승인 여부
