# Future Improvements

## 1. 개선 원칙

미래 개선은 MVP가 안정적으로 운영된 뒤 실제 사용 피드백과 장애 기록을 기반으로 결정합니다.

## 2. 후보 개선 사항

후보:

- 추가 공공 출처 확대
- AI 중복 판단 보조 강화
- 메시지 품질 평가 자동화
- 테스트 Channel과 운영 Channel 분리 자동화
- 더 정교한 지역별 그룹핑
- 운영 알림 채널 추가
- 간단한 상태 리포트 생성

## 3. 계속 제외할 가능성이 높은 항목

MVP 철학상 신중해야 하는 항목:

- 모바일 앱
- 개인화 경로 추천
- 사용자 계정
- 결제
- 관리자 대시보드
- 실시간 지도 기능

## 4. 개선 검토 기준

개선은 다음 중 하나를 만족해야 합니다.

- 알림 누락을 줄입니다.
- 중복 발행을 줄입니다.
- 운영 부담을 줄입니다.
- 메시지 이해 시간을 줄입니다.
- 비용을 크게 늘리지 않습니다.

## 5. 사용자 입력 필요 항목

- `[사용자 입력 필요]` MVP 이후 가장 우선할 개선 후보
- `[사용자 입력 필요]` 계속 제외할 기능 목록 승인 여부
