# Archived Sprint Documents

This directory stores historical DDD and sprint-planning documents from the early design phase.

These files are kept for traceability only. They are not the current source of truth for implementation, operations, scheduling, runtime sources, or deployment behavior.

Use current context in this order:

1. `project-memory/STATE.md`
2. `project-memory/OPEN_ISSUES.md`
3. `project-memory/REPOSITORY_MAP.md`
4. `project-memory/DECISIONS.md`
5. `project-memory/ARCHITECTURE.md`
6. `docs/handoff-current-status.md`
7. Source code and tests

Some archived sprint documents may be stale or contain older encoding issues.
