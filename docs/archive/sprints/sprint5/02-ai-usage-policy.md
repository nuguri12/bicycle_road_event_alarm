# AI Usage Policy

## 1. AI 사용 원칙

AI는 추론과 문장 압축이 필요한 작업에만 사용합니다.

허용:

- 자전거 이용자 관점의 짧은 요약
- 영향도 사유를 자연스럽게 설명
- 여러 이벤트를 중요도 순으로 읽기 쉽게 정리
- 애매한 중복 후보의 보조 판단

금지:

- 날짜 계산
- URL 생성
- 장소를 임의 보정
- 없는 통제 정보 생성
- 개인화 경로 추천
- 공식 출처가 아닌 정보로 사실 보강

## 2. AI 호출 전 필터링

AI 호출 전에 코드가 수행해야 하는 작업:

- validation_status가 `valid`인 이벤트만 선택
- publish_candidate가 true인 이벤트만 선택
- 이미 발행된 이벤트 제외
- 날짜가 알림 기간 밖인 이벤트 제외
- 필수 필드가 없는 이벤트 제외
- 이벤트 수가 너무 많으면 영향도와 날짜 기준으로 상위 이벤트만 선택

## 3. AI 응답 검증

AI 응답은 그대로 신뢰하지 않습니다.

검증 항목:

- 메시지가 비어 있지 않습니다.
- 허용된 최대 글자 수를 넘지 않습니다.
- 입력에 없는 URL을 포함하지 않습니다.
- 입력에 없는 날짜나 장소를 포함하지 않습니다.
- 금지된 개인화 경로 안내를 포함하지 않습니다.

검증 실패 시:

- 재시도하지 않고 fallback 메시지를 생성합니다.
- 실패 사유를 구조화 로그로 남깁니다.

## 4. 모델 선택 정책

모델은 구현 시점에 공식 문서와 비용 기준을 확인해 선택합니다.

선택 기준:

- 한국어 짧은 요약 품질
- 낮은 비용
- 빠른 응답
- 안정적인 구조화 출력 지원

## 5. 사용자 입력 필요 항목

- `[사용자 입력 필요]` 월간 OpenAI 비용 상한
- `[사용자 입력 필요]` AI 응답 실패 시 재시도 없이 fallback으로 갈지 여부
- `[사용자 입력 필요]` 구현 시점에 사용할 OpenAI 모델 선택 기준 승인 여부
