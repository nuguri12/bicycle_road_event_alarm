# Channel Structure

## 1. Channel 목적

Telegram Channel은 소규모 자전거 그룹이 주말 라이딩 전에 확인하는 단방향 공지 공간입니다.

## 2. Channel 운영 방식

MVP 기본:

- 하나의 공용 Channel에 발행합니다.
- 사용자별 맞춤 메시지는 발행하지 않습니다.
- Channel 댓글, 반응, 토론 그룹은 시스템 설계 범위에서 제외합니다.

## 3. Channel 이름 권장 기준

권장 이름:

- 지역과 목적이 드러나는 이름
- 너무 긴 이름은 피합니다.
- 공식 기관처럼 오해될 수 있는 이름은 피합니다.

예:

- `주말 자전거 주의구간 알림`
- `서울 경기 라이딩 주의 알림`

## 4. 메시지 운영 기준

- 주말 전 정해진 시간에 발행합니다.
- 같은 내용은 반복 발행하지 않습니다.
- 빈 이벤트 목록은 기본적으로 발행하지 않습니다.
- 긴급 수정 공지는 MVP 이후 검토합니다.

## 5. 테스트 Channel

권장:

- 실제 Channel과 별도 테스트 Channel을 둡니다.
- 구현과 배포 검증은 테스트 Channel에서 먼저 수행합니다.
- 운영 발행 전 테스트 Channel ID와 운영 Channel ID를 분리합니다.

## 6. 사용자 입력 필요 항목

- `[사용자 입력 필요]` 운영 Channel 이름
- `[사용자 입력 필요]` 테스트 Channel을 별도로 만들지 여부
- `[사용자 입력 필요]` 빈 이벤트 목록 메시지를 Channel에 발행할지 여부
